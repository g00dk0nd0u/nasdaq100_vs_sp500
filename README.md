# NASDAQ100 vs S&P500

This repository contains monthly price data for the NASDAQ-100 and the S&P 500 indices.

## Files

- `data/NASDAQ100_monthly.txt` - NASDAQ-100 monthly data
- `data/SP500_monthly.txt` - S&P 500 monthly data
- `doc/index.html` - Documentation or visualization output

## Purpose

Use this repository to compare historical monthly performance of the NASDAQ-100 and the S&P 500.

## Notes

- Data files are stored in `data/`.
- Add your analysis scripts or notebooks in the repository root or a dedicated folder.
